# Bhupendra logo

The current website logo is the user-supplied `Logo Bhupendra.png`, copied unchanged to `public/brand/bhupendra-logo.png` and `app/icon.png`.

It replaces the old “db.” header/footer lockup and browser icon. The reusable `components/Brand.tsx` component displays the image with responsive sizing and a home link. Change `logo` in `lib/business.ts` to replace it later.

The earlier generated concept remains in `public/brand/bhupendra-logo-green.png` as an unused design file.
